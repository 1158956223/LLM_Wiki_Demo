# 项目目标
构建一个本地优先、Markdown 优先的 LLM Wiki 系统，为使用者提供可靠、可检索的大语言模型相关知识库，支持离线访问与长期维护。

# 关键问题
- 如何以 Markdown 文件形式高效组织、交叉引用和检索 LLM 相关知识？
- 如何确保内容在没有网络连接或外部服务时仍可完整浏览与编辑？
- 如何支持用户以最简工具（文本编辑器、Git）参与贡献和维护？

# 范围
- 提供 LLM 基础概念、关键模型、训练范式、评测方法、安全伦理等领域的知识条目。
- 设计清晰的目录结构和元数据规范，支持本地文件系统浏览。
- 支持 Markdown 内链、标签和全文搜索（通过本地工具）。
- 提供初始化脚本和贡献指南，便于快速部署和协作。

# 非范围
- 不依赖专用数据库或动态后端服务。
- 不内置实时在线协作功能，协作通过 Git 等版本控制工具进行。
- 不追求自动化内容生成或 AI 辅助编辑，当前阶段以人工编纂为主。

# 当前工作假设
- 用户具备基本的 Markdown 编辑能力和 Git 使用经验。
- 内容结构以层级目录为主，每个条目为独立 Markdown 文件。
- 初始内容主要覆盖通用 LLM 知识，暂不深入特定领域应用。
